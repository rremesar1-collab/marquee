## Marquee 0.14.6 · names script 3.15.2

- **Names script 3.15.2 (FPP):** with 1 or 2 names waiting, the short names break could let the last name run into the announcer's closing ("if you want your name in lights, visit..."), mostly when Names per break is set under 6. The script was counting more name spots than the short break's audio has. Now the short breaks use exactly their own spots: 2 names are each said twice (or once each with fewer names per break), 1 name twice, always before the closing. The full break is unchanged. FPPs with the Marquee plugin update themselves.
- README: spoken names (ElevenLabs) work on FPP 9 too; they only need FPP's Play Media command. Only kids' pictures need FPP 10.
