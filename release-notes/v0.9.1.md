**Marquee 0.9.1**

- **Names per break** (Settings → Names & FPP → card 1). Names scrolling too fast on your matrix? Show fewer names per break and each one stays up longer. At 3 names per break, every name gets twice the time, so a scrolling message moves half as fast. The names still fit the same part of your names break audio, and any extra names go up in the next break.

Update the **Marquee plugin on your FPP** too (Content Setup → Plugin Manager), or download the new marquee_names.py if you put the script on by hand.
