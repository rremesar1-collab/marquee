**Marquee 0.8.7 · Marquee Festive 2.11.8 · FPP plugin names script 3.9.0**

- **Your Name in Lights: only during the playlists you pick.** New in **Settings → Names & FPP → Only during these playlists**. If you run a background or static playlist alongside your show, tick your main show playlist and names wait for it instead of going up during the static one. Your FPP's playlists show up as checkboxes once the names script checks in (or type the names in). Leave it empty to keep putting names up during any playlist, like before.
- Checked against **FPP 10.3**.
- The FPP plugin's names script is now 3.9.0. Update the Marquee plugin in FPP's Plugin Manager to get the playlist option.
