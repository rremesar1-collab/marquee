## Marquee 0.20.12 · Marquee Festive 2.23.12

- **Show each name once:** a new "Repeat names to fill the break" switch in Settings → Names in Lights (names break tab). Leave it on and, when fewer names are waiting than your names break has room for, they go up again so your screens aren't empty. Turn it off and each name goes up once.
- **The name buzz waits for the names break:** kids who asked for a buzz get it when the names break actually starts, a few seconds before their name goes up, never while nothing is playing.
- Update the Marquee plugin on your FPP too (Content Setup → Plugin Manager), to 3.17.3 or newer, for these to work.
