## Marquee 0.15.1 · names script 3.15.3

- **Slower scrolling in the short breaks:** with 1 or 2 names waiting and Names per break under 6, each name now goes up once and gets the whole stretch of the short break, so scrolling text moves about half as fast as in 3.15.2. Each name is still said before the closing.
- **Still text on two lines:** with Text set to Still on a pixel matrix, the message goes on one, two or three centered lines, whichever lets the letters be biggest (the name on its own line after the comma). It's sized for bold capital letters, so it no longer runs off the sides of the screen. Line breaks are sent as real line breaks, which FPP 9 and FPP 10 both draw.
- **A name is always said:** if the break was running late and a name's first turn got skipped, the name is now said on its next turn instead of going up silently.

FPPs with the Marquee plugin update themselves. If you put the script on by hand, download it again from Names in Lights → Connect your FPP.
