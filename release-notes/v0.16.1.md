## Marquee 0.16.1 · names script 3.16.1

- **Fixed: names stopped after the FPP restarted.** The names script keeps a note that it's running. After a restart that note could point at some other program, and the script thought it was already running and didn't start, so names and test names stopped going up. It now checks the note properly and always starts. Update the Marquee plugin in FPP's Plugin Manager to get it.
- **Screen status stays up to date.** Before, the setup panel only knew whether your TV, projector or matrix could be reached from the FPP's last setup check, so a screen that was off then kept showing "Can't reach" even after you turned it on. Now the FPP checks each screen again every couple of minutes and the panel updates by itself.
- **Check again, right there.** A screen that can't be reached has its own Check again button, and while you have the setup page open the FPP looks again every 15 seconds, so you don't wait.
- **Every screen that's off is named**, not just the first one.
- Names always went up on a screen once it was on. Only the status message was out of date.
