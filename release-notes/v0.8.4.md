**Marquee 0.8.4 · Marquee Festive 2.11.5**

Two fixes for the Marquee FPP plugin from 0.8.3:

- **Updating the plugin on your FPP no longer disconnects it.** FPP can run the plugin's uninstall step while updating, and that step was removing your connection settings, so names stopped going up until you pasted the connection code again. Your connection now stays (use Disconnect on the plugin page if you want the FPP to forget your website).
- **No restart needed after an update.** Names script 3.8.1 notices when it has been updated, by the plugin or by a new copy you put on by hand, and starts the new version by itself.

### Update your FPP
Using the plugin: FPP → Content Setup → Plugin Manager → Update on Marquee. If it says "Not connected" afterwards (the old version removed the settings during this one update), paste your connection code once more. Put the script on by hand: download marquee_names.py 3.8.1 from Settings → Names & FPP and replace the old one.
