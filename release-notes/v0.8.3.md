**Marquee 0.8.3 · Marquee Festive 2.11.5**

### New: the Marquee FPP plugin
The easiest way to get names on your screens. No files to upload, no Command Presets.
1. On the FPP that plays your show: **Status/Control → Settings → User Interface Level → Developer** (FPP 10.1 only loads plugins from an address at this level; you can set it back afterwards).
2. **Content Setup → Plugin Manager**, paste `https://raw.githubusercontent.com/rremesar1-collab/fpp-marquee/main/pluginInfo.json` in the search box and click **Install**.
3. On your website: **Marquee → Settings → Names & FPP → Connect your FPP**, copy the connection code.
4. On the FPP: **Content Setup → Marquee**, paste the code and click **Connect**.

Your screens and the names break timing now come from your website on every check-in, so changes there reach the FPP by themselves. Already put the script on by hand? Delete its FPPD_STARTED Run Script preset and `marquee_names.py` from Scripts first; the plugin won't run two copies.

### Your screens: text style and size
Each screen now has **Text** (Automatic, Still or Scrolling), **Size** (Automatic, Small to Fill the screen, or **Custom** with an exact font size) and **Scroll speed**. On Automatic, small pixel matrices (64 pixels tall or less, like a 40 x 10 seed matrix) get the name in one big line that scrolls across when it won't fit. TVs and projectors look the same as before.

### Kids' Corner
- The **Show Wall** is now right on the Kids' Corner page, under the activities, instead of a tab inside Make a Light Show. Links to `/kids/#show-wall` still work.
- The Kids' Corner button on the home page tells visitors they can vote for the kids' shows while the contest is open.
- Optional: the newest kids' shows on the home page (off by default; Customize → Kids' Corner).
- Publishing a contest entry or show video clears your page cache, so it shows up for visitors right away.

### Also
- Behind the Lights: when you hide some tiles, the rest stay centered.
- Get help: during a support session Marquee Support can run the setup check, set up the names break playlists again or restart the names script on your FPP. Each one shows in your chat.
- The names script waits for the network and FPP after a reboot before its setup check, so the check isn't full of start-up errors.

### Update your FPP script
Using the plugin? Click **Update** on Marquee in FPP's Plugin Manager. Put the script on by hand? Download **marquee_names.py 3.8** from Settings → Names & FPP and replace the old one. The text style settings need 3.8.
