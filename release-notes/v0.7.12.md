**Marquee 0.7.12 · Marquee Festive 2.10.4**

- **Spoken names (optional):** an ElevenLabs voice reads each name out loud as it goes up ("Merry Christmas, Emma!"). Set it up in Marquee → Settings → Connections → "Say each name out loud": paste your ElevenLabs key, load your voices, test one. Clips are saved, so a repeated name costs nothing. An optional "talking faces" effect moves your singing faces' mouths while each name is spoken. Needs the updated `marquee_names.py` (3.1) on your FPP.
- **Coloring pages:** Remove takes a standard page out of the Settings list; "Removed pages" lets you restore it.
