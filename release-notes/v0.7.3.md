**Updates now work on shared hosting.** Many hosts put lots of websites on one server address, and GitHub only answers 60 update checks an hour per address. When that limit is used up, Marquee now reads the public release page instead, so you still see new versions.

Also:
- The Plugins page shows when Marquee last checked for updates and what it found.
- If a check fails, Dashboard → Updates says why. Marquee tries again every 15 minutes.

The Marquee Festive theme is unchanged (2.9.8).
