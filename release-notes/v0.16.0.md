## Marquee 0.16.0 · names script 3.16.0

Easier Names in Lights setup, with fewer settings to get right.

- **Names break with no fixed timing.** With Marquee's simple names break (no names sequence of your own), the FPP runs the break itself: the show pauses, the intro plays, each name is up for as long as it takes to read and say, then the outro. One name makes a short break, six a longer one, and a name can never run into the outro. **Build the names break audio again once** (Names in Lights → Names break → Names break audio) to get it. Shows with their own names sequence keep the timed break.
- **Readable text by itself.** On Automatic, a pixel matrix shows the message still, on one to three centered lines, when the letters come out big enough to read. Otherwise it scrolls one big line at reading speed, and a long message gets fewer, longer turns instead of flying across. "Names per break" is now "Most names per break", inside a new **Timing** section with the settings you don't normally need.
- **Last names breaks.** The setup panel at the top of Names in Lights lists the last few breaks: every name, whether it went up on your screens, and whether it was said (or why not, in plain words).
- **No more silent repeats.** Every spoken name plays under a fresh file name, so the same name coming round again is always said.
- **Your own names break audio** timings ("First name at", "Closing starts at") are on the website now, under Use my own names break audio.
- **FPP 9:** the Marquee plugin for FPP installs on FPP 9 too.

FPPs with the Marquee plugin update themselves.
