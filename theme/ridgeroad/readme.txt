Requires at least: 6.0
Requires PHP: 7.4
License: GPLv2 or later

The festive Christmas look for the Marquee light show plugin.

== Install ==
1. Install and activate the Marquee plugin first (Plugins -> Add New -> Upload Plugin).
2. Appearance -> Themes -> Add New -> Upload Theme -> choose this zip -> Install -> Activate.
3. Marquee -> Settings holds everything about your show. Appearance -> Customize -> Show Website
   has the wording (tips, guestbook, Kids' Corner) and the look (background picture, snow).

Without the Marquee plugin, visitors see a short "getting ready" page.
