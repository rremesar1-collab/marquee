MARQUEE - "YOUR NAME IN LIGHTS" SETUP GUIDE
============================================

Kids type their first name on your website. Between songs, your show plays a
short "names" break and shows each name on your screens (a matrix, a
projector, a TV - anything FPP can draw text on). Names never cover a song.

A small script on your FPP does the work. It reaches out to your website, so
you never open ports on your router.

You need: a recent FPP (tested with FPP 10), Marquee on your website, and
about 30 minutes.


1. MAKE A SCREEN FPP CAN WRITE ON (Pixel Overlay Model)
-------------------------------------------------------
On the FPP that drives each screen:
  FPP -> Input/Output Setup -> Pixel Overlay Models -> Add.
  - Pick the channels of your matrix (or the virtual display / HDMI model
    for a projector or TV).
  - Give it a short name with no spaces, like MatrixText or TVText.
  - It must be wider than it is tall. If FPP shows it taller than wide, swap
    "strings" and "nodes" for that model in xLights and export again.

You can have up to 4 screens, on the same FPP or on other FPPs on your
network.


2. MAKE THE NAMES BREAK (a short sequence + playlist)
-----------------------------------------------------
How names go up (Marquee -> Settings -> Names & FPP, top of the page):
  - Between songs (a names break, recommended): when kids have sent names,
    your FPP slips a short "names break" sequence in after the current
    song, puts the names up one by one, then goes back to your playlist.
    Needed for spoken names, the break audio and themed sequences.
  - During songs, on a spare screen: names go up on a TV or projector your
    sequences don't use while the show keeps playing. No names break
    needed: skip to step 3. (Names script 3.5 or newer.)

Let Marquee make it: Settings -> Names & FPP -> "Sequence maker".
Choose your xlights_rgbeffects.xml (from your xLights show folder; it's read
in your browser, never uploaded) and Marquee makes the names break .xsq for
you: screens left dark for the names, gentle effects on the rest of the
house, a flash on every prop as each name goes up.

Or make it yourself: in xLights, a sequence about 30 seconds long called
"Names in Lights":
  - Keep your screens dark or very dim from 4 seconds on - the names are
    drawn on top by FPP, 6 names, 3.75 seconds apart.
  - Light the rest of the house however you like (a gentle twinkle works).
  - Optional: a short "Your Name in Lights!" title at the start.
Either way it has to be RENDERED in xLights before FPP can play it: open
the .xsq in xLights (if it asks for the music, pick the names break audio
or any soft instrumental), click Render All, check it in the house
preview, and Save. Saving writes the .fseq next to it. FPP plays the .fseq,
not the .xsq.

Send the .fseq (and its music) to your FPP master: in xLights, Tools -> FPP
Connect, tick your FPP and the sequence, and click Upload (it sends both); or
upload them in FPP -> Content Setup -> File Manager. Then make a playlist with just
that sequence. Name the playlist "Names in Lights" (or put your own name in
Marquee -> Settings -> Names & FPP).

Do NOT add this playlist to your show schedule. The script slips it in after
the current song only when names are waiting.


3. FILL IN YOUR SCREENS ON YOUR WEBSITE
---------------------------------------
WP Admin -> Marquee -> Settings -> Names & FPP -> "Connect your FPP":
  - FPP playlist with your names break: the playlist from step 2.
  - One row per screen:
      Screen             a name for you, like Matrix or TV
      FPP address        the FPP that drives it (127.0.0.1 = your FPP master
                         itself, otherwise its address, like 192.168.1.60)
      Overlay model name exactly as in step 1
  - Click Save settings.
Then download both files:
  - marquee_names.json   (your settings - it holds your private key, so
                          don't share it or post it online)
  - marquee_names.py     (the script)


4. PUT THE FILES ON YOUR FPP MASTER
-----------------------------------
  FPP -> Content Setup -> File Manager -> Upload both files:
  marquee_names.py and marquee_names.json.
  FPP files the .py under Scripts and the .json under Uploads (it won't show
  in the Scripts list). That's fine: the script looks in both places.


5. START THE SCRIPT WITH FPP
----------------------------
  First, so "Run Script" shows up in the list:
  FPP -> Status/Control -> Settings -> UI -> User Interface Level: Advanced.
  (On "Basic", FPP hides some commands, including Run Script.)

  FPP -> Status/Control -> Command Presets -> Add:
    Preset name: FPPD_STARTED
    Command:     Run Script   (in the "Events" group of the list)
    Script:      marquee_names.py
  Save, then restart FPPD (Status page -> Restart FPPD).
  You can set the User Interface Level back to Basic afterwards: the preset
  keeps working.


6. CHECK IT
-----------
Names go up only while your show PLAYLIST is playing on this FPP (the one
running the script). A single sequence or "Play Media" won't bring the names
break. More than one FPP? Put the script on the one that plays the show.

Within a minute, WP Admin -> Marquee -> Settings -> Names & FPP shows
"FPP last checked in ..." and a setup check with a green tick or a red cross
for each part. Fix any red line (see below), then restart FPPD again.

Then turn on "Your Name in Lights" (Marquee -> Settings -> Features), start
your show, and send a test name from the Kids' Corner. It goes up after the
current song. You can approve, block or pause names in WP Admin -> Show
Control.

If you use a terminal on your FPP (SSH), you can also run:
  python3 /home/fpp/media/scripts/marquee_names.py --check   (check + test name)
  python3 /home/fpp/media/scripts/marquee_names.py --setup   (make the settings
                                                             file by answering questions)
The log is in FPP -> File Manager -> Logs -> marquee_names.log.



7. SAY EACH NAME OUT LOUD (OPTIONAL, ELEVENLABS)
------------------------------------------------
Your website can have an ElevenLabs voice read each name over your radio
station as it goes up: "Merry Christmas, Emma!". Your website makes the
audio, so your ElevenLabs key never goes on the FPP.

  a. Make an ElevenLabs account (elevenlabs.io). Developers -> API Keys ->
     Create: give it "Text to Speech" access and "Voices: Read".
  b. WP Admin -> Marquee -> Settings -> Names & FPP -> "Say each name out
     loud": paste the key, click "Load my voices", pick one (the voice your
     show announcer uses sounds best), and click "Test voice". Turn on
     "Speak the names" and Save settings.
  c. Upload marquee_names.py again (it must be version 3.1 or newer) and
     restart FPPD. The setup check gets a line for sound.

The names break audio (do this once, and again whenever you change it):
  - Your break needs a quiet stretch for the names. Marquee makes the
    sound for you: Settings -> Names & FPP -> "Names break audio".
  - Type an intro and an outro line (or keep the examples), give the
    length of your names sequence (FPP -> File Manager -> Sequences shows
    it), and optionally pick an instrumental MP3 (no singing or talking).
    Without one, a soft music box that comes with Marquee is used.
  - Click "Build the break audio". Your voice says the lines, the music
    plays soft under the names, and everything is leveled to the loudness
    show songs are usually mastered to. You can listen before you leave.
  - It also makes short breaks for when only 1 or 2 names are waiting
    (each name is said twice).
  - Within a minute, the names script downloads the audio and sets up
    the playlists by itself: your break playlist plays the new audio, and
    "<your break playlist> 1" and "<your break playlist> 2" are created for
    the short breaks. Your xLights sequence isn't changed. The setup check
    shows "names break audio from the website is set up".
  - The names timing (when the first name goes up, seconds per name) is
    set to match the audio automatically.
  - Spoken names play in their own sound slot (FPP 10 or newer), over the
    break audio, and are leveled to the same loudness.
  - With fewer than 6 names, the screens repeat them, and each one is said
    again every time it goes up.

Themed sequences (optional): kids pick the show their name goes up in.
  - Settings -> Names & FPP -> "Sequence maker" makes them for you:
    give it your layout (and your own names break .xsq if you have one,
    so the themes keep its music and timing), tick Candy Cane Swirl,
    Snowfall... or describe your own (uses the Need help? AI), and download
    the .xsq files. Render each one in xLights and Save (see step 2).
  - Or make them yourself: copy your names break and change the house
    effects to fit the theme. Keep the screens dark where the names go and
    use soft music with no singing.
  - Put each one in its own FPP playlist, for example "Names - Snowfall".
  - Settings -> Names & FPP -> "Themes kids can pick": turn it on and
    add each theme with its playlist, when the first name goes up and the
    seconds per name ("Use it" in Sequence maker fills this in).
    Each card kids see shows a little animated house in that theme's
    colors, or a picture you choose (Classic can have one too).
  - Kids then tap a picture when they send their name. After the current
    song, the theme the longest-waiting kid picked plays; kids who picked
    the same theme go up together, and anybody who waited a whole break
    goes up in the next one whatever it is. Your regular break is the
    "Classic" choice.
  - Names script 3.4 or newer. The setup check lists each theme's playlist.

Talking faces (optional): make your singing faces' mouths move while each
name is spoken.
  - In xLights, make a short sequence (about 4 seconds) with a talking
    mouth on your singing faces: a Faces effect with a phoneme loop, or
    mouth shapes switching "AI, O, E, MBP, rest" every 0.1-0.2 seconds.
    Only put effects on the face models.
  - In the sequencer, right-click the face model -> Export Model -> pick
    "FPP Effects (.eseq)". Name it, for example, "Names Talking", and upload
    it in FPP -> File Manager -> Effects.
  - More than one face: export one effect per face (or one for a model
    group of all of them, if your xLights version allows it).
  - Type the effect name in "Talking faces effect" on your website (several
    names with commas: Names Talking 1, Names Talking 2), Save, and
    download marquee_names.json again (it carries the names to your FPP).
  The script starts the effect as each name is spoken and stops it when
  the voice ends.

Cost: about 25 ElevenLabs credits per name (one per letter). A name that
was already said is free after that: the clip is saved on your website
(uploads/marquee-voice) and on your FPP (File Manager -> Audio, files that
start with marquee-voice-; the newest 300 are kept).

If a spoken name doesn't work, the name still goes up on the screens. The
last problem shows on your website under "Say each name out loud".

WHAT THE RED LINES MEAN
-----------------------
"no settings file"          marquee_names.json isn't on this FPP yet.
                            Upload it in File Manager (step 4), then
                            reboot the FPP.
"the private key is wrong"  Download marquee_names.json again from your
                            website and upload it again.
"could not reach the website"
                            Check your FPP has internet (FPP -> Status).
"bot protection blocked the request"
                            Some web hosts (SiteGround, for example) block
                            programs. Ask your host to allow requests to
                            /wp-admin/admin-ajax.php?action=rr_names_pull,
                            or turn off their "bot protection" for it.
"no playlist named ..."     The playlist name on your website and on FPP
                            must match exactly (step 2 and 3).
"no overlay model named ... on ..."
                            The overlay model name or FPP address in your
                            screens is wrong, or that FPP is off.
"taller than wide"          Swap strings and nodes for that model in xLights
                            (step 1).
"no 'Play Media' command"   Your FPP is too old to play the spoken names.
                            Update FPP.
"no effect named ..."       The talking faces effect isn't in FPP -> File
                            Manager -> Effects, or the name doesn't match.
"could not download the spoken name" (in the log)
                            Your host's bot protection may block the FPP
                            from wp-content/uploads/marquee-voice/. Ask your
                            host to allow it, like the names check above.


PRIVACY
-------
The website only gets first names, checked against a word filter, and
names you block never go up. The script sends your website what FPP is
playing (for Show Control) and its setup check - nothing else. With spoken
names on, your website sends the first name and greeting to ElevenLabs to
make the audio.
